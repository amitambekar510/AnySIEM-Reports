# Phishing Simulation and Awareness Report: Section Blueprint

Blueprint for a phishing simulation and awareness report. Report in aggregate and never name individuals.

## Section index

| ID | Section | Include |
|---|---|---|
| PS0 | Cover and Document Control | Always |
| PS1 | Campaign Design | Always |
| PS2 | Results | Always |
| PS3 | Group Comparison | Always |
| PS4 | Trends | Always |
| PS5 | Training Completion | Always |
| PS6 | Reporting Behavior | Always |
| PS7 | Recommendations | Always |
| PS8 | Sign-Off and Acknowledgement | Always |

## PS0: Cover and Document Control

**Purpose:** Identify the document, period, and owner.

**Content blocks**

- Cover with title, period, and classification
- Document control table

**Inputs from the user**

- Document ID format
- Author, reviewer, approver roles

**Data from the SIEM (vendor-neutral)**

- None

**Compliance hooks (indicative, verify before citing):** ISO/IEC 27001

## PS1: Campaign Design

**Purpose:** Describe the exercise.

**Content blocks**

- Scenario
- Audience groups
- Period
- Approval record

**Inputs from the user**

- Design
- Approval

**Data from the SIEM (vendor-neutral)**

- None

**Compliance hooks (indicative, verify before citing):** ISO/IEC 27001, SEBI CSCRF 2024, RBI IT/Cyber

**Writing note:** Report in aggregate. Never name individuals.

## PS2: Results

**Purpose:** Show outcomes.

**Content blocks**

- Delivered, opened, clicked, credentials entered, reported
