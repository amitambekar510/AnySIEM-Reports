# Threat Intelligence Digest: Questions

Ask in batches. Skip anything already answered or already known from the SIEM profile.

## Batch 1: Context

1. What is the organization or client name, and who will read this report (leadership, client, auditor, regulator)?
2. Is the SOC in-house, provided by a managed service provider, or hybrid? What are the operating hours?
3. What reporting period and audit period does this report cover?
4. What classification label and document ID format should the report use?
5. Template mode (placeholders) or populated mode (filled values)? Exact numbers or diplomatic wording?

## Batch 2: Delivery model

1. Do you deliver IOCs through a secure access link, feed URLs, or both?
2. How long is a secure link valid, and how is access tracked?
3. How often are IOCs reviewed and refreshed in practice?
4. How do you remove outdated or superseded IOCs?

## Batch 3: Integration support

1. Which feed integration methods do you actually support?
2. What do you not support?

## Batch 4: Distribution

1. Who receives this digest (organization, role)?
2. What copy ID and distribution method will you use?

## Batch 5: Frameworks

1. Which regulations and standards apply to you? (see the framework list in the compliance library)
2. Do you need to show evidence for an audit (for example an annual technology audit)? Which auditor or regulator is the audience?
3. Are there mandatory reporting windows or log retention periods you must evidence?

## Batch 6: Recommendations and close

1. Which recommendation areas should be included?
2. Is there anything else you want in this report (a dashboard summary, a custom table, a regulator-specific appendix)?
3. Which roles should sign off? Should the watermark and footer attribution stay or be removed?
