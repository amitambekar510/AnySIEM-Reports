# Daily SOC Summary and Shift Handover: Data Needs

Vendor-neutral list of the data each section needs. Use the SIEM profile to decide where each item comes from.

| Section | Data needed | If unavailable |
|---|---|---|
| DS1 Shift Overview | Platform status; Source health exceptions | Ask the user. If still unavailable, mark as not available from the current configuration and offer to list it under Findings. |
| DS2 Alert and Incident Activity | Alert counts by severity; Case status counts | Ask the user. If still unavailable, mark as not available from the current configuration and offer to list it under Findings. |
| DS3 Notable Events | Most significant alerts or cases | Ask the user. If still unavailable, mark as not available from the current configuration and offer to list it under Findings. |
| DS4 Platform and Log Source Exceptions | Sources with no data in the shift; Ingestion delay indicators | Ask the user. If still unavailable, mark as not available from the current configuration and offer to list it under Findings. |
| DS5 Open Items and Handover | Open case list | Ask the user. If still unavailable, mark as not available from the current configuration and offer to list it under Findings. |
