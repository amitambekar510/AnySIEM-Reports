# Writing Style

## Language

- US English: organization, defense, authorized, prioritize, color.
- Plain, professional, and compliance-oriented. Short sentences.

## Compliance wording

- Prefer "evidence", "control", "observed", "in accordance with", "as defined
  in", "subject to", and "responsibility of".
- Describe what was done and what evidence supports it. Do not make promises.
- Never write "fully compliant" unless the user supplied evidence and the
  framework text supports the claim.
- Do not write "no incidents" or "no breaches" unless confirmed. Use
  "No confirmed security breaches were identified during the reporting period,
  based on the data available to the SOC."

## Disclosure level

- **Exact mode:** show the numbers the user provided.
- **Diplomatic mode:** use generic, accurate statements. Example: "SLA
  commitments were met for the applicable severity levels." Never imply a
  number that you do not have.

## Responsibility boundaries

State clearly who owns each action (SOC, client IT, vendor). Where an action is
outside the SOC's contracted scope, say so plainly and add it as a
recommendation instead.

## Vendor neutrality

Describe capabilities ("correlation rules", "log source health"), not products.
Use the user's product names only where the user supplied them.

## Awareness content

Give guidance directly in the report. Do not send readers to third-party
websites unless the user requests it.
