# How to Use AnySIEM-Reports with an AI Assistant

## Option 1: Assistant that can read GitHub

Paste the starter prompt from the README. The assistant reads
`AI_INSTRUCTIONS.md` and begins at the template catalog.

## Option 2: Assistant without GitHub access

Download the repository as a ZIP, upload it (or paste `AI_INSTRUCTIONS.md`, the
`core/` folder, and the template you want), then use the same starter prompt.

## What to prepare

- Your SIEM product name and version
- Reporting and audit period
- Which regulations and standards apply to you
- Your SLA definitions and severity scheme
- Any dashboards or numbers you want in the report

## What you get

One PDF in the template's color theme, with an optional watermark and footer.
Remove the branding by telling the assistant, or by editing `core/branding.yaml`.
